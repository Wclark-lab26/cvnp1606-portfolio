## User goal:



Make text easier to read after a windows 11 refresh without changing unrelated system settings



## Tool path tested:



Settings → Accessibility → Text sizes



Steps:



1. Press **Windows key** and **I** to open Settings.

2. Select **Accessibility**.

3. Find **Text size**.

4. Adjust slider to **150%**.

5\. Verify that it is easier to read across any Windows applications.

## Verified result



The user confirmed that **150% Text Size** restored readability issues and resolved the issue occurring with the Windows 11 refresh.



## When to escalate:



If display problems continue after Accessibility Text size and Display scale settings have been reviewed, collect the following information and escalate for further investigation into issue:



- Device model



- Monitor model



- Screen resolution



- Graphics adapter information



- Current display scaling percentage
