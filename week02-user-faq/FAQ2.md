## User goal:



Make computer display color without changing unrelated systems



## Tool path tested:



Settings → Accessibility → Color filters



Steps:



1. Press **Windows key** and **I** to open Settings.

2. Select **Accessibility**.

3. Find **Color filters**.

4. Disable Color filters.

5. Verify that the display is showing in full color.

screenshots/FAQ2-accessibility.png

## Verified result



The user confirmed that turning off Color filters showed full color on display



## When to escalate:



If display problems continue after Accessibility Text size and Display scale settings have been reviewed, collect the following information and escalate for further investigation into issue:



\- Device model



\- Monitor model



\- Graphics adapter information
