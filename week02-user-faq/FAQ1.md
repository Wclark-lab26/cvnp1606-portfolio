## User goal:



Fix visible horizontal screen tearing split after a windows 11 refresh without changing unrelated system settings



## Tool path tested:



Settings → System → Display → Advanced Display



Steps:



1. Press **Windows key** and **I** to open Settings.

2. Select **System**.

3. Find **Advanced Display**.

4. Find **Choose a refresh rate**.

5. Change refresh rate **60 Hz** to **165 Hz**
   
6. Restart computer to instantly apply changes

## Verified result



The user confirmed that **165 Hz** has fixed the horizontal screen tearing after restart



## When to escalate:



If screen tearing continues after Display and Advanced Display settings have been reviewed Collect the following information and escalate for further investigation into issue:



- Device model



- Screen resolution



- Graphics adapter information



- Current display scaling percentage
