



How to enforce new Time-out policy:



* Open intune



* Go to Devices



* Go to Configuration 



* Click the plus icon and click create



* Click New Policy



* Select Platform: Windows 10 and later



* Profile type: Setting Catalog



* Search for and add "Screen Timeout"



* Configure the setting to the enforced value



* On the assignments tab, target the profile to an Entra ID group or use an Intune filter
