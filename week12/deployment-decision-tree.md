



New hire:



* Pre-provisioning



* Reason-The user completes a shorter OOBE because the heavy lifting was done in the staging step. This reduces the time the user spends at the Enrollment Status Page on first login and assists in the hiring process, making it easier.



Shared kiosk:



* Self-deploying mode



* Reason- due to this being a shared kiosk, it uses TPM 2.0 to authenticate it instead of individual logins due to multiple users



Remote employee:



* User driven



* Reason-being remote and not always on site, they should always put their credentials into the system so no one else can log in.



Replacement laptop for an existing employee:



* User-driven



* Reason-a replacement should log in with correct credentials into Entra to keep security clean and make sure the people working for ACME know its a individual that works for the company
